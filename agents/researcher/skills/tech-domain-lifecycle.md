# Skill: Tech Domain Lifecycle

**Agent:** Researcher  
**Used by:** `tech-macro-regime.md`  
**Output section:** Domain Lifecycle

Use this skill to classify where a technology domain sits in its lifecycle.

## Lifecycle Checks

```text
early-research       - papers, demos, prototypes, few production users
developer-adoption   - active developer trials, examples, starter kits
production-adoption  - real products, case studies, operational learnings
enterprise-adoption  - procurement, compliance, vendor support, large teams
maintenance          - mature, stable, mostly incremental movement
decline              - falling usage, stale maintainers, ecosystem migration
```
