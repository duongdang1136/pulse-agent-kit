# Skill: Tech Source Registry

**Command:** `/tech-source-registry <domain>`  
**Agent:** Researcher  
**Output:** `Tech-Source-Registry`

Use this skill to maintain a registry of high-signal technology sources for a domain.

## Goal

- Catalogue trusted sources.
- Classify source type and reliability.
- Track best-fit domains and signal patterns.
- Record known bias, lag, or false-positive risks.
- Make future trend discovery repeatable.

## Output Contract

Use `agents/researcher/templates/Tech-Source-Registry.md`.
