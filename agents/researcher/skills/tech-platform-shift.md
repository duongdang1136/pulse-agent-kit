# Skill: Tech Platform Shift

**Agent:** Researcher  
**Used by:** `tech-macro-regime.md`, `tech-signal-discovery.md`  
**Output section:** Platform Shift

Use this skill to detect platform, runtime, cloud, hardware, protocol, or distribution changes that can create new technology trends.

## Checks

- Runtime or framework shift.
- Cloud/vendor platform support.
- Hardware acceleration or device capability shift.
- Protocol, standard, or API shift.
- Distribution shift: marketplace, app platform, browser, IDE, agent runtime.
