# Skill: Adoption Signal

**Agent:** Researcher  
**Used by:** `tech-trend-confirmation.md`

Use this skill to confirm whether a candidate trend has real adoption beyond attention.

## Checks

- Usage: downloads, install base, traffic, public deployments.
- Developers: GitHub activity, issues, examples, tutorials.
- Production: case studies, architecture posts, incident learnings.
- Enterprise: jobs, procurement, security reviews, managed offerings.

## Output

| Adoption Signal | Evidence | Source ID | Strength | Notes |
|---|---|---|---|---|
| [signal] | [evidence] | SRC-001 | [High / Medium / Low] | [notes] |

**Adoption verdict:** [confirmed / promising / weak / unknown]
