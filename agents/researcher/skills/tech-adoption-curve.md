# Skill: Tech Adoption Curve

**Agent:** Researcher  
**Used by:** `tech-macro-regime.md`, `tech-trend-confirmation.md`  
**Output section:** Adoption Curve

Use this skill to assess adoption movement across developers, teams, vendors, and enterprises.

## Checks

- Developer adoption: tutorials, package downloads, GitHub activity, examples.
- Team adoption: production case studies, architecture posts, migration notes.
- Ecosystem adoption: integrations, plugins, managed services, vendor support.
- Enterprise adoption: compliance, procurement, support contracts, job postings.
