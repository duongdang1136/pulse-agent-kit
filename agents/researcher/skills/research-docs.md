# Skill: Research Docs

**Agent:** Researcher  
**Used by:** `tech-signal-discovery.md`, `tech-trend-confirmation.md`, `/research-docs`

Use this skill to collect evidence from official docs, changelogs, RFCs, roadmaps, standards, migration guides, and release notes.

## Evidence To Capture

- Official positioning and intended use.
- Latest release or changelog movement.
- Breaking changes and migration guidance.
- Roadmap, RFC, or standardization signal.
- Compatibility and support matrix.
